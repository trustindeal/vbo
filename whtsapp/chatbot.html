Quick guide

Chatbot setup in 5 simple steps

In steps ko follow karke aap apna WhatsApp bot easily ready kar sakte hain.

  1. Bot on karein: Enable automatic replies tick karein aur reply timeout set karein.
  2. Handoff timeout set karein: Human support ke baad bot kitni der mein dobara active hoga, minutes mein choose karein.
  3. Flow banayein: Build Conversation Flow se Simple welcome ya Support menu template select karein.
  4. Steps edit aur connect karein: Message, Menu, Question ya Handoff mein details fill karein; phir steps ko order mein connect karein.
  5. Live karein: Pehle Save Draft, phir Validate. Errors na hon to Publish karein.
Yaad rakhein: Customer ko reply sirf published flow se jayega. Handoff node mein employee number aur notification template bhi set kar sakte hain.
