📘 Meta Setup Guide
1. Open Meta Business Manager and create/open the client's Business Account.
2. Set up WhatsApp Business Account (WABA) and add the dedicated WhatsApp number.
3. Open the WhatsApp API / API Setup section and note the Phone Number ID.
4. Copy the WABA ID and Business ID from Meta Business settings.
5. Create/copy the required WhatsApp Cloud API access token.
6. Make sure the required WhatsApp permissions and webhook setup are completed.
7. Enter the values above and click Save Meta Connection.

📘 Meta Setup Guide

Quick guide for connecting a new client

1. Meta Business
Create or open the client's Meta Business account.

2. WhatsApp Business Account
Create/open the WABA and add the client's dedicated WhatsApp number.

3. Developer / Cloud API
Open the WhatsApp Cloud API setup and get the Phone Number ID.

4. Required IDs
Collect the WABA ID and Business ID from Meta.

5. Access Token
Create the appropriate WhatsApp API access token with the required permissions.

6. Webhook
Configure the common VBONotif webhook and subscribe the WABA as required.

7. Templates
Create/approve WhatsApp message templates in Meta whenever template messaging is required.

8. Link here
Enter the Meta IDs and token in the Link Meta form and save the connection.
