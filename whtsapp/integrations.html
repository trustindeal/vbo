API Documentation

Use the API from your own server or software. Keep your API key on the server; never place it in a public webpage, URL, or shared code.

List approved templates

GET https://app.vbo.co.in/api/v1/whatsapp/public/templates

Send a template

POST https://app.vbo.co.in/api/v1/whatsapp/public/send-template

Required headers

X-Client-ID: YOUR_CLIENT_ID X-API-Key: YOUR_API_KEY Content-Type: application/json

Example request body

{ "template_name": "vbonotif_test", "language": "en", "recipients": ["91XXXXXXXXXX"], "parameters": [] }

Actual template name, language, required parameters, account settings and recipient limits must match your approved configuration. Each accepted message may incur a charge.

URL Generator

Generate a ready-to-use API request for external software. This tool does not send a message. Do not put API credentials in a URL.

Generated URL

Opening the URL sends the message immediately. The API key is included in the URL, so browser history and server logs may expose it. Generate short-lived test URLs and avoid sharing them.

API Credentials

Generate a key for your account. Regenerating it immediately invalidates your previous key. The new key is displayed only once.

Never share this key publicly or put it in a browser URL. If lost, regenerate it; the old key will stop working.
